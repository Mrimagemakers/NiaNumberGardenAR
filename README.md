# Nia & the Number Garden — Interactive AR Math Adventure

A mobile-friendly interactive math experience designed to pair with a book’s QR/AR activation.

## Live Demo
https://YOUR_USERNAME.github.io/nia-number-garden-ar/

## Features
- 20 interactive pages (counting, patterns, addition, subtraction)
- Score + confetti feedback
- Swipeable number carousels
- Read-to-me narration controls

## Customize for other books
Edit the `pages[]` content and `APP_CONFIG` settings in `index.html`.
